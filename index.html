Quickstart: key to resting order

First create the management key on Profile → Settings → Novig API.

    Signing a request

    Every request is signed with your key's Ed25519 or P-256 private key. Novig only holds the public half.

    Headers

    • Novig-Key-Id: the key ID
    • Novig-Timestamp: Unix milliseconds
    • Novig-Signature: base64 signature

    String to sign, one field per line

    1. NOVIG-V3
    2. The timestamp
    3. The HTTP method
    4. The path
    5. The canonical query, sorted and percent-encoded
    6. Hex SHA-256 of the body (of empty data if none)

    Environments

    Keys only work in the environment where you made them. Production checks your IP and your phone's last geolocation.
